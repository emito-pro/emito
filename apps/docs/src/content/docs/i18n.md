---
title: Translate the UI
description: Override Emito's component copy with a message catalog, no fork needed.
---

The components ship English copy but read every string from a **message
catalog** you can override, so no fork is needed. Pass a (deep-)partial `messages`
through `EmitoThemeProvider` (or a standalone `EmitoMessagesProvider`); anything
you omit falls back to the English defaults.

```tsx
import { EmitoThemeProvider, type PartialEmitoMessages } from '@emito/react';

const messages: PartialEmitoMessages = {
  preferences: {
    title: 'Preferencje powiadomień',
    categories: { transactional: 'Bezpieczeństwo i transakcje', product: 'Aktualizacje' },
    channels: { email: 'E-mail', sms: 'SMS', inApp: 'W aplikacji' },
    locks: { alwaysSent: 'Zawsze wysyłane' },
  },
  inbox: { title: 'Powiadomienia', markAllRead: 'Oznacz wszystkie jako przeczytane',
           markAsRead: 'Oznacz jako przeczytane', archive: 'Archiwizuj',
           snooze: 'Odłóż', emptyTitle: 'Brak powiadomień' },
  snooze: { until: 'Odłóż do', oneHour: '1 godzina', tomorrow: 'Jutro' },
  integrations: { title: 'Integracje', add: 'Dodaj integrację' },
};

<EmitoThemeProvider appearance={{ variables: { colorPrimary: '#16a34a' } }} messages={messages}>
  <InboxPopover bell={<NotificationBell />} preferencesHref="/settings/notifications" />
</EmitoThemeProvider>
```

`messages` is a **deep-partial** `PartialEmitoMessages`: you only need to
specify the keys you want to override, and everything else is merged from the
English defaults.

The full catalog has four top-level sections: `preferences` (title,
categories, channel labels, lock-icon tooltips), `inbox` (header, per-item
actions, empty state, footer link), `snooze` (the snooze picker's label and
its 5 time options), and `integrations` (the personal-integrations manager).
The example above only overrides a few keys from each; see
`defaultMessages` (below) for the complete shape.

Building custom components against the same catalog? Three exports do the
work:

- **`useMessages()`**: returns the merged catalog inside any component under
  `EmitoThemeProvider`/`EmitoMessagesProvider`.
- **`defaultMessages`**: the built-in English catalog, useful as a reference
  for available keys.
- **`mergeMessages`**: the same deep-merge helper the providers use
  internally, if you need to compose catalogs yourself.
